Alcheringa 2026 is a single-page event website for the Department of CSE (AIML) at IEM Kolkata, in a maroon-and-beige theme with a matching dark mode. It brings the semester’s hackathons, workshops, guest lectures and cultural nights together in one place, built around the two-day annual fest on 12 and 13 December.

Visitors can browse and search the event lineup, filter it by category, and watch a live countdown to the next event. They can also register for a pass through a validated form that shows a live pass preview and issues a pass ID. Other sections cover an hour-by-hour fest schedule, guest speakers, a photo memory wall, the event coordinators, an FAQ, and contact and feedback forms.

It is plain HTML, CSS and JavaScript, built as a coursework project (IT Workshop).
